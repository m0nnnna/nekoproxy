Settings

These settings are pushed to agents when you click Apply. Choose which agents to push to below. Controller URL is the URL agents use to reach this controller (e.g. https://controller.example.com for HTTPS). ~nya

Controller & agent

Agents set NEKO_AGENT_CONTROLLER_URL to this. Use https:// when behind SSL.

Agents must send this when registering. Set on agents as NEKO_AGENT_AGENT_SECRET.

GeoIP filtering

Allow or block connections by country. Agents need GeoLite2-Country.mmdb and NEKO_AGENT_GEOLITE2_DB_PATH set.

Connection & lockdown

0 = disabled. Close proxy connections after this many seconds with no data.

Forces 120s idle timeout, default geo blocklist (CN,RU,KP,IR) if geo off.

Forward proxy

When enabled, each agent listens on this port as an HTTP/HTTPS forward proxy. Devices point their proxy settings at agent-ip:port and traffic exits from the agent. If NEKO_AGENT_UPSTREAM_PROXY is set on an agent, traffic exits from that VPS instead.

0 = disabled. Common choices: 3128, 8080, 8118.

Leave blank for no authentication. Format: user:pass.

DNS forwarder

When enabled, each agent listens on this port for DNS queries (UDP + TCP) and forwards them to the upstream resolver. Point devices' DNS at agent-ip:port. Port 53 requires root/admin; use 5353 or another unprivileged port if needed.

0 = disabled. Common choices: 53 (root only), 5353, 5300.

Format: host or host:port. Examples: 1.1.1.1, 8.8.8.8:53, 9.9.9.9.
